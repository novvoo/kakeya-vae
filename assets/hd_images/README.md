# 高清训练图片目录

在此目录放置真实高清图片，用于提升模型的颜色与细节泛化能力。

## 建议放置

**10–30 张真实高清图**，分辨率 512px 及以上（最高不超过 4096px）。

支持格式：`.jpg`、`.jpeg`、`.png`、`.webp`、`.bmp`

## 推荐内容类型

| 类型 | 原因 | 示例 |
|---|---|---|
| 人像 / 动物 | 肤色、毛发的丰富色彩与细节 | 人物肖像、宠物照片 |
| 自然风景 | 绿色、蓝色等自然色系的完整色阶 | 森林、山脉、海景、天空 |
| 静物 / 食物 | 多样的色彩饱和度与纹理 | 花卉、美食、日常物品 |
| 建筑 / 街景 | 直线、文字、招牌等高频结构 | 城市街景、室内空间 |

## 训练数据占比

容量阶段训练数据混合比例：

- 40% 参考图文卡（校准基准）
- 30% 程序化图文卡（随机生成）
- **30% 本目录真实图片**

## 注意事项

- 确保图片版权合规，仅用于训练目的
- 图片宽高需不小于 128px，建议 512–1024px
- 目录为空时训练会自动 fallback 到参考图文卡，但泛化效果受限
